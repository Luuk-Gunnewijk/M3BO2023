# The Escape
The Escape is a game about a grandpa Junkie whose house is on fire. So of course escaping is the last thing on his mind, what is on his mind, is all his meds. Can you get a new high score and fill Grandpa's addiction?

# Get a better high score
In The Escape, you can collect medicine which will increase your high score.
Grandpa does not like the fire however.
